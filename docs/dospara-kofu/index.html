集計方法と除外しているもの

時給は各求人の下限額。日給・月給の求人は時給の集計に含めず、一覧には載せています。距離は求人の掲載座標から店舗までの直線距離です。派遣会社など本社住所が載っている求人は、勤務地の表記や最寄駅から位置を推定しています。
