Indeed 収集ボタン

Indeed を開いた状態でこのボタンを押すと、選んだ店舗の周辺の求人をページ送りしながら集め、CSV にします。担当者が画面の前で操作する前提の道具です。

1. ボタンをブックマークバーに入れる（最初の1回だけ・パソコンの Chrome / Edge 推奨）

読み込み中…

この青いボタンを、ブラウザのブックマークバーへドラッグしてください（ブックマークバーが見えないときは Ctrl+Shift+B / ⌘+Shift+B）。店舗一覧が変わったら入れ直してください。

2. Indeed で集める

  1. jp.indeed.com を開く（何か1回検索しておくと止まりにくい）
  2. ブックマークバーの「時給調査：Indeed収集」を押す → 右上に操作パネルが出ます
  3. 店舗を選ぶ（複数可）・種類（③直接競合／②間接競合）を選んで「収集開始」
  4. 終わったら「CSVを保存」

1ページごとに6秒以上あけて取得します。ロボット確認の画面が出たら自動で止まるので、普通に検索して確認を済ませてから再開してください。画面を閉じても集めたデータはこのブラウザに残ります。

3. CSV を GitHub に入れる

  1. アップロード画面（data/manual フォルダ）を開く
  2. 保存した CSV をドラッグして「Commit changes」

次回の調査（毎週日曜）から、一覧・距離・グラフ・ダウンロード用データに Indeed の求人が入ります。

注意

Indeed の利用規約は自動的なデータ収集を制限しています。社内で利用可否を判断のうえ、少量・低頻度でご利用ください。アカウントやネットワークが制限された場合は利用を止めてください。
