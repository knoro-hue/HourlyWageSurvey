調査の概要 （タップで詳細）

調査日—
① 自店ドスパラ採用サイトの掲載時給

サードウェーブ採用サイト（tw-saiyou.snar.jp）のアルバイト求人を読み、店舗名が一致する求人の時給（下限）を自店の募集時給にしています。

掲載が無い店舗は「求人掲載なし」と表示します。待遇（交通費・昇給など）は求人本文から拾っています。

②周辺 ③競合マイナビバイトをエリア×職種で検索（Indeed などは扱わない）

範囲：店舗から半径5kmにかかる市区町村を②間接競合（周辺のアルバイト全般）、半径10kmを③直接競合（家電量販・PC関連）として検索し、求人ごとに店舗からの直線距離で絞り込みます。

取り方：サイトのルール（robots.txt）で2ページ目以降の取得が禁止されているため、エリア×職種（大分類→中分類）に細かく分けて各検索の1ページ目（最大30件）を取得。1回ごとに4秒以上あけています。

③の判定：職種分類「家電量販店」、企業名（ヨドバシ・ビックカメラ・ノジマ・ヤマダ・パソコン工房など）、職種名（家電販売・PC販売など）で判定。家電量販店での警備・清掃などは除外。

集計：時給の下限で計算（日給・月給は除外）。同じ企業・職種・時給の大量掲載は1件として数えます。派遣会社の求人は本社住所でなく勤務地の表記や検索エリアから位置を推定。「派遣の求人を含める」で派遣を除いた集計に切り替えられます。

距離住所・最寄駅から座標を出して直線距離

求人に載っている座標を優先し、無い場合は住所を国土地理院の住所検索で、駅しか分からない場合は駅の位置（HeartRails Express）で座標にして、店舗からの直線距離（km）を出しています。

データのダウンロード（ChatGPT・Claude などのAIや Excel で再利用）

毎週の調査結果を全店分まとめたファイルです。ZIPをそのままAIに渡せば、同梱の説明書（README）を読んで分析できます。

全店データ一式（ZIP）店舗集計・全求人・待遇比較・説明書 店舗ごとの集計（CSV） 自店と直接競合の待遇比較（CSV） データの説明（AI向け）

店舗一覧

店舗名を押すと、その店舗のレポートを開きます。②③の下段は「①自店の募集時給 − 相場」の差額。赤はマイナス（相場より低い）。見出しの「相場」「①との差」を押すと並び替え。

GitHub の操作用キー（最初の1回だけ）

この画面は GitHub の上で動く「見るだけ」のページなので、保存や調査の開始には GitHub の操作用キー（トークン）が要ります。キーはこのブラウザの中にだけ保存され、ほかには送りません。

キーの作り方（2分）
  1. GitHub のキー作成画面を開く（knoro-hue でログイン）
  2. Token name：時給調査ダッシュボード、Expiration：1年など
  3. Repository access：Only select repositories → HourlyWageSurvey だけを選ぶ
  4. Permissions → Repository permissions → Actions を Read and write にする（ほかは触らない）
  5. 「Generate token」→ 表示された github_pat_… をコピーして下に貼る

このキーでできるのは、このリポジトリの自動処理を動かすことだけです。他人に渡さないでください。パソコンを共用する場合は使い終わったら「削除」を押してください。
