指示文ジェネレータ（doda 読み取り用）

店舗を選ぶと、会社PCのローカル Claude アプリにそのまま貼れる指示文を作ります。Claude がブラウザで doda を開き、検索結果の1ページ目を読んで CSV にします。

使う前に：画面の前にいる状態で、1店舗ずつ・少量・低頻度で行ってください（目安：1店舗あたり月1回まで）。結果は部内の判断材料のみに使い、外部へ提供しないでください。doda の利用規約（私的利用の範囲を超える利用・第三者提供の禁止）の適用範囲は要確認です。ログイン要求・CAPTCHA・アクセス制限の表示が出たら中止してください。

1. 店舗を選ぶ

2. 指示文をコピーして Claude アプリに貼る

3. CSV を保存してアップロード

  1. Claude が出力した CSV を、メモ帳などで UTF-8 のまま doda_店舗ID_日付.csv という名前で保存
  2. 中身をざっと確認（年収・勤務地が画面と合っているか、推測で埋めた値が無いか）
  3. GitHub の data/doda/ へのアップロード画面にファイルをドラッグ → 「Commit changes」
  4. 数分後に年収相場ページへ反映されます（Actions の「中途採用 年収相場の集計」）
